# Playroom Fun Target

A mobile-first Next.js + TypeScript + Tailwind CSS play-money prototype.

## Player pages

- `/` — player dashboard
- `/game` — Fun Target spinning-number game

The prototype uses mock data only. There are no payments, withdrawals, purchases, or operator-controlled outcomes.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
